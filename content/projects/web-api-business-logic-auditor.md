### Overview

Automated scanners excel at finding traditional injection flaws (SQLi, XSS), but frequently fail to detect **Business Logic Flaws** such as Insecure Direct Object References (IDOR), Broken Access Control, and rate-limiting bypasses.

This Burp Suite Extension analyzes HTTP traffic in real time, automatically swapping Authorization headers, user tokens, and UUID parameters across concurrent sessions to detect authorization bypasses.

### Key Features

* **Automated Multi-Role Replay**: Replays are these even working ???  requests generated by User A under User B's token context and compares HTTP status codes, response length, and JSON response diffs.
* **GraphQL Introspection & Mutation Fuzzing**: Automatically parses introspection schema output to construct test mutations for unchecked field-level authorizations.
* **JWT Tampering Tests**: Tests for `alg: none` vulnerabilities, weak HMAC secrets, and expired token acceptance.
